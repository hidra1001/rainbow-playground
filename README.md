# 무지개 놀이터 (갤럭시탭용 앱)

산수·한글·두뇌 놀이 세 가지를 하나로 묶은 홈 화면 앱(PWA)입니다.
인터넷 주소로 한 번 열어서 "홈 화면에 추가"하면 일반 앱처럼 아이콘이 생기고, 그 뒤로는 인터넷이 없어도 실행됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 놀이터 홈: 오늘의 미션 4개, 출석 스트릭, 스티커북, 무지개 길, 자유 놀이, 설정 |
| `math.html` | 산수 놀이 (6~9살 × 4가지) |
| `hangul.html` | 한글 놀이 (6~9살 × 4가지) |
| `brain.html` | 두뇌 놀이 (6~9살 × 4가지) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 저장 (서비스 워커) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 갤럭시탭에 설치하기

1. 이 폴더를 인터넷(HTTPS)에 올립니다. `deploy.ps1`을 실행하면 GitHub Pages에 올라갑니다.
2. 갤럭시탭의 **삼성 인터넷** 또는 **Chrome**으로 그 주소를 엽니다.
3. 삼성 인터넷: 메뉴(≡) → **현재 페이지 추가** → **홈 화면**. Chrome: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**.
4. 홈 화면에 생긴 🌈 아이콘을 누르면 전체 화면으로 열립니다. 한 번 열어 두면 오프라인에서도 됩니다.

> 파일을 태블릿에 직접 복사해서 `index.html`을 열어도 놀 수는 있지만, 그 방법으로는 홈 화면 앱 설치와 오프라인 저장이 되지 않습니다.

## 매일 달라지는 것

- **오늘의 미션 4개**: 날짜를 씨앗으로 골라서 날마다 조합이 바뀝니다. 산수·한글·두뇌에서 하나씩 + 👑 도전 미션(한 살 위 난이도) 하나. 어제와 같은 놀이는 피합니다.
- **요일 테마**: 일요일 무지개, 월요일 동물, 화요일 과일, 수요일 우주, 목요일 바다, 금요일 공룡, 토요일 마법. 화면 색과 인사말이 바뀝니다.
- **오늘의 낱말**: 날마다 다른 낱말과 그림.
- **스티커북**: 미션 4개를 다 하면 스티커 1개(80종), 별 36개 이상이면 반짝 스티커(10종)까지.
- **무지개 길**: 미션을 다 한 날마다 한 칸 전진, 30칸을 채우면 무지개 성 도착 후 새 여행 시작.
- **연속 출석**: 하루를 건너뛰면 0으로 돌아갑니다.
- 문제 자체도 매번 무작위로 만들어지며, 별은 한 번에 맞힌 문제에만 줍니다.

## 나이 바꾸기

설정 탭에서 6살 / 7살 / 8살 / 9살을 고르면 다음 날 미션부터 그 나이 기준으로 나옵니다. 자유 놀이에서는 어떤 나이든 바로 고를 수 있습니다.
