# 무지개 놀이터 (갤럭시탭용 앱)

6~7살을 위한 산수·한글·두뇌·아케이드 놀이를 하나로 묶은 홈 화면 앱(PWA)입니다. 태블릿 가로 화면(16:9·16:10)에서 스크롤 없이 한 화면에 들어가도록 만들어졌습니다.
인터넷 주소로 한 번 열어서 "홈 화면에 추가"하면 일반 앱처럼 아이콘이 생기고, 그 뒤로는 인터넷이 없어도 실행됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 놀이터 홈: 오늘의 미션 5개, 출석 스트릭, 스티커북, 무지개 길, 자유 놀이, 설정·부모님 리포트 |
| `math.html` | 산수 놀이 (6가지: 더하기 빼기, 세기, 10 만들기, 빠진 수, 문장제, 돈 세기 등) |
| `hangul.html` | 한글 놀이 (6가지: 낱말 찾기, 빠진 글자, 글자 만들기·첫소리, 낱말 만들기, 받아쓰기, 흉내 내는 말) · 낱말 470개 |
| `brain.html` | 두뇌 놀이 (5가지: 짝 맞추기, 규칙 찾기, 순서 기억, 다른 그림 찾기, 순서대로 누르기) |
| `arcade.html` | 무지개 아케이드 (베네치아식 게임 4가지: 떨어지는 식·낱말, 풍선 터뜨리기, 두더지 잡기) |
| `layout.css`, `layout.js` | 가로 화면 두 칸 배치 (왼쪽 문제, 오른쪽 답) |
| `voice.js`, `audio/` | 밝은 목소리로 미리 녹음한 낱말·문장 발음 클립 631개 (없으면 기기 목소리) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 저장 (서비스 워커) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 갤럭시탭에 설치하기

1. 이 폴더를 인터넷(HTTPS)에 올립니다. `deploy.ps1`을 실행하면 GitHub Pages에 올라갑니다.
2. 갤럭시탭의 **삼성 인터넷** 또는 **Chrome**으로 그 주소를 엽니다.
3. 삼성 인터넷: 메뉴(≡) → **현재 페이지 추가** → **홈 화면**. Chrome: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**.
4. 홈 화면에 생긴 🌈 아이콘을 누르면 전체 화면으로 열립니다. 한 번 열어 두면 오프라인에서도 됩니다.

> 파일을 태블릿에 직접 복사해서 `index.html`을 열어도 놀 수는 있지만, 그 방법으로는 홈 화면 앱 설치와 오프라인 저장이 되지 않습니다.

## 매일 달라지는 것

- **오늘의 미션 5개**: 학습 2개(산수·한글) + 게임 2개(아케이드) + 두뇌 놀이 또는 👑 도전 미션(한 살 위 난이도)이 번갈아 나옵니다. 날짜를 씨앗으로 골라 날마다 조합이 바뀌고 어제와 같은 놀이는 피합니다.
- **요일 테마**: 일요일 무지개, 월요일 동물, 화요일 과일, 수요일 우주, 목요일 바다, 금요일 공룡, 토요일 마법. 화면 색과 인사말이 바뀝니다.
- **오늘의 낱말**: 날마다 다른 낱말과 그림. 누르면 읽어 줍니다.
- **스티커북**: 미션 5개를 다 하면 스티커 1개(80종), 별 45개 이상이면 반짝 스티커(10종)까지.
- **새 친구(아바타) 해금**: 3일·6일·10일 연속 출석, 스티커 20·40개, 무지개 성 도착 때마다 새 아바타가 열립니다.
- **무지개 길**: 미션을 다 한 날마다 한 칸 전진, 30칸을 채우면 무지개 성 도착 후 새 여행 시작.
- **연속 출석**: 하루를 건너뛰면 0으로 돌아갑니다.
- **부모님 리포트**: 설정 탭에서 최근 7일 별 개수와 평균이 낮은 놀이를 볼 수 있습니다.
- 문제 자체도 매번 무작위로 만들어지며, 별은 한 번에 맞힌 문제에만 줍니다.

## 목소리

낱말·문장은 마이크로소프트 '선희' 음성을 조금 높이고 20% 느리게 해서 미리 녹음했습니다(`audio/`). 설정 탭에서 기기 목소리로 바꿀 수도 있습니다.
클립을 다시 만들려면 `python gen-audio.py` (edge-tts 필요)를 실행합니다.

## 나이와 난이도

- 설정 탭에서 6살 / 7살을 고르면 그 나이 기준으로 미션이 나옵니다. (8살·9살 내용은 코드에 남아 있지만 화면에서는 숨겼습니다.)
- **난이도 조정 −3 ~ +3**: 설정 탭이나 각 놀이 첫 화면에서 고릅니다. 쉬우면 시간이 넉넉해지고(두더지·풍선·떨어지는 것) 보기가 적고 힌트가 빨리 나오며, 어려우면 빨라지고 보기가 늘고 비슷한 보기로 헷갈리게 나옵니다. 6살은 수의 범위(5→20), 글자 수, 받침 붙이기까지 바뀝니다.
- 낱말 만들기·받아쓰기의 글자 타일은 정답 글자 수의 2배 이상 나옵니다.
